# KanbanFlow Manual Testing

Manual testing of two flows in KanbanFlow, a web-based kanban board: task management and WIP (work-in-progress) limits. Testing is done on the free plan with my own account, in Chrome on desktop.

## What's in this repository

- [test-plan.md](test-plan.md): scope, approach, environment, entry and exit criteria, and how bugs are reported.

## How the testing is done

- Manual testing only, using normal user actions on my own account.
- Expected results are written before execution, based on KanbanFlow's official pages and on-screen text.
- Every result in this repository comes from my own test runs.

## Status

The test plan is complete. Test cases are next, then execution against the live app, bug reports, and a test summary. This README is updated as each part is added.
